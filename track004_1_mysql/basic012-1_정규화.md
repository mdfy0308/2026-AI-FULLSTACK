## ■진행 1. 정규화 1NF ~ 5NF

#### STEP 1) 정규화?
1. 관계형 데이터 모델 - 데이터간 관계에 초점을 둔 모델
2. 이상(Anomaly) - 공간 낭비
    - 삽입, 갱신, 삭제 이상
3. 정규화? 이상을 제거

### STEP 2) ERD 핵심 구성요소
1. 개체(Entity) - 테이블, 개념의 정보 단위
2. 속성(Attribute) - 테이블의 열, 가장 작은 논리적 단위
3. 관계(Relationship) - 외래키, 테이블 간의 관계를 외래키 등을 구현해서 사용

예) emp( FK:deptno ) - dept( PK:deptno )

### STEP 3.5) BCNF
1. 관계형 데이터베이스의 X → Y (결정자→종속자)가 성립할 때 
   모든 결정자가 후보키이면 [BCNF]가 된다.
2. 식별자로 쓰이는 속성이 일반 속성에 종속되지 않아야한다.
3. 3NF를 통해서도 제거되지 않은 3.5 정규화

※ KEY?
   : 튜플(행, 레코드)을 구분할 수 있는 기준 필드

NO(PK)    NAME     AGE     jumin
1        장동건     54      720514
2        장동건     54      721214

1) 후보키 - 기본키로 사용할 수 있는 속성 (NO, jumin)
    유일성(유일하게 식별), 최소성(식별시 최소한의 속성)
2) 기본키 - 후보키에서 선택한 주요한 키(main key) - NO
3) 대체키 - 후보키에서 선택되지 않은 키(jumin)
4) 외래키 - 테이블과 테이블을 연결해주는 속성(예: deptno)
5) 슈퍼키 - 속성+속성 집한된 구성키
    std_id + course_id
    유일성(다른 튜플 구분 O), 최소성(X)

### STEP 4) 4NF - 다치 종속 제거
1. 같은 테이블 내의 독립적인 두개 이상의 컬럼이 다른 컬럼에 종속
2. 단일 A와 다중값 B
과목(A)    프로그래밍
담당교수(B) A1, A2
교재코드(B) Z1, Z2

과목 → 교수코드 | 교재 코드
